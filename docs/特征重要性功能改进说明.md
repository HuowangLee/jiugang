### 6. 使用示例

#### 查看特征重要性CSV
```python
import pandas as pd

# 读取特征重要性
fi = pd.read_csv('output-ahead-20251027_083127/feature_importance.csv')

# 查看前20个最重要特征
print(fi.head(20))

# 查看特定特征的重要性
print(fi[fi['feature_name'].str.contains('price_ahead')])

# 统计重要性
print(f"总特征数: {len(fi)}")
print(f"重要性总和: {fi['importance_gain'].sum():.2f}")
print(f"平均重要性: {fi['importance_gain'].mean():.2f}")
```

#### 分析特征重要性
```python
import matplotlib.pyplot as plt

# 查看重要性分布
fi['importance_gain'].hist(bins=50)
plt.xlabel('Importance')
plt.ylabel('Frequency')
plt.title('Feature Importance Distribution')
plt.show()

# 累积重要性
fi['cumsum'] = fi['importance_gain'].cumsum() / fi['importance_gain'].sum()
print(f"前10个特征累积贡献: {fi.iloc[9]['cumsum']:.2%}")
print(f"前20个特征累积贡献: {fi.iloc[19]['cumsum']:.2%}")
```

### 7. 特征重要性类型

#### Gain (默认)
- 表示该特征对模型性能提升的平均贡献
- 更能反映特征对预测的实际影响
- **推荐使用**

#### Weight (备用)
- 表示该特征在所有树中被使用的次数
- 如果gain不可用则自动使用weight

### 8. 常见问题

#### Q: 特征重要性为0是什么意思？
A: 说明该特征在模型中未被使用，可以考虑删除

#### Q: 如何选择重要特征？
A: 可以根据累积贡献度（如前80%的特征）或绝对阈值进行选择

#### Q: 滞后特征如何命名？
A: 格式为 `原特征名_lag_N`，其中N是滞后步数

#### Q: 可视化图表只显示30个特征？
A: 是的，为了图表清晰度。完整列表请查看CSV文件

### 9. 注意事项

1. 特征重要性仅反映在当前模型和数据下的重要性
2. 不同的数据划分可能产生不同的重要性排序
3. 重要性低不一定意味着特征无用，可能存在交互效应
4. 建议结合业务知识和多次实验结果综合判断
