## 更新概述

为项目添加了灵活的滞后特征构造方法，现在支持两种模式：
1. **Direct模式**: 直接拼接滞后特征（原有方法）
2. **Statistical模式**: 构造统计量特征（新增方法）

## 功能详解

### Direct方法（原有方法）

**配置**:
```yaml
feature_engineering:
  lag_length: 3
  lag_method: 'direct'
```

**生成特征** (以feature1为例):
- `feature1_lag1`: 1个时刻前的值
- `feature1_lag2`: 2个时刻前的值
- `feature1_lag3`: 3个时刻前的值

**特点**:
- 保留完整历史信息
- 特征数量: N特征 × lag_length

### Statistical方法（新增方法）

**配置**:
```yaml
feature_engineering:
  lag_length: 3
  lag_method: 'statistical'
```

**生成特征** (以feature1为例):
1. `feature1_lag1`: 上一时刻的值
2. `feature1_diff1`: 与上一时刻的差值 (当前值 - lag1)
3. `feature1_rolling_mean`: 滚动平均（窗口=lag_length）
4. `feature1_rolling_std`: 滚动标准差（窗口=lag_length）
5. `feature1_diff3`: 与3个时刻前的差值 (当前值 - lag3，当lag_length>1时)

**特点**:
- 提取统计信息（趋势、波动）
- 特征数量: N特征 × 5（固定）
- 降低维度，减少过拟合

## 使用方法

### 方法1: 修改现有配置文件

编辑任意配置文件，修改 `lag_method` 参数：

```yaml
feature_engineering:
  lag_length: 3  # 设置滞后长度
  lag_method: 'statistical'  # 选择方法: 'direct' 或 'statistical'
```

然后运行：
```bash
python main.py --config config/your_config.yaml
```

### 方法2: 使用新的示例配置

直接使用提供的示例配置：
```bash
python main.py --config config/config_ahead_statistical_lag.yaml
```

## 向后兼容性

✓ 所有现有配置文件默认使用 `lag_method: 'direct'`，保持原有行为
✓ 如果配置中未指定 `lag_method`，默认为 `'direct'`
✓ 不需要修改任何现有代码或配置即可正常运行

## 选择建议

| 场景 | 推荐方法 | 理由 |
|------|---------|------|
| 数据量 < 10000 | statistical | 降低过拟合风险 |
| 数据量 > 10000 | 都可以 | 充足的数据支持更多特征 |
| lag_length ≤ 3 | direct | 特征数量可控 |
| lag_length > 3 | statistical | 避免维度爆炸 |
| 关注趋势和波动 | statistical | 显式提取这些信息 |
| 需要完整历史 | direct | 保留所有信息 |

## 实现细节

### 分组支持

两种方法都支持按组构造特征：

```yaml
feature_engineering:
  lag_length: 3
  group_key: 'station_id'  # 按站点分组
  lag_method: 'statistical'
```

当设置 `group_key` 时，滞后特征和统计量会在每个组内独立计算，确保不会跨组泄露信息。

### NA值处理

- 前 `lag_length` 行会产生NA值
- 系统会自动移除这些行（通过 `remove_lag_na()` 方法）
- 不影响后续训练和预测

### 滚动窗口计算

Statistical方法使用pandas的rolling API：
```python
rolling_mean = df[feature].shift(1).rolling(
    window=lag_length, 
    min_periods=1
).mean()
```

- `shift(1)`: 确保不使用当前时刻的值（避免数据泄露）
- `min_periods=1`: 在窗口未满时仍计算（使用可用数据）
- 分组时自动在组内计算

## 示例对比

假设有2个特征，lag_length=5:

**Direct方法**:
- 生成特征数: 2 × 5 = 10个
- 特征列表: `feature1_lag1, feature1_lag2, ..., feature1_lag5, feature2_lag1, ..., feature2_lag5`

**Statistical方法**:
- 生成特征数: 2 × 5 = 10个
- 特征列表: 
  - feature1: `_lag1, _diff1, _rolling_mean, _rolling_std, _diff5`
  - feature2: `_lag1, _diff1, _rolling_mean, _rolling_std, _diff5`

当lag_length=10时：
- Direct: 2 × 10 = 20个特征
- Statistical: 2 × 5 = 10个特征（维度降低50%）

## 未来扩展

可以考虑添加更多统计量，如：
- 滚动最大值/最小值
- 滚动中位数
- 指数移动平均(EMA)
- 自相关系数
- 变化率

可以在 `_build_statistical_lag_features()` 方法中轻松添加这些特征。
