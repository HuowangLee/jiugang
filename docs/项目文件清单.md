# 项目文件清单

本文档列出了重构后的所有文件及其用途。

## 📁 核心模块（必需）

### 1. 主程序
- **main.py** (160行)
  - 训练流程的主入口
  - 协调各个模块的运行
  - 命令行参数解析

### 2. 配置管理
- **config_manager.py** (60行)
  - 加载和管理YAML配置文件
  - 提供便捷的配置访问接口
  - 支持嵌套配置访问

### 3. 工具函数
- **utils.py** (90行)
  - 数据读取：`safe_read_csv()`
  - 列检查：`quick_check_columns()`
  - 符号转换：`sign_label()`, `sign_agreement()`
  - 一致性计算：`per_date_sign_agreement()`
  - 权重计算：`calculate_sample_weights()`

### 4. 数据加载
- **data_loader.py** (120行)
  - `DataLoader` 类
  - 读取训练/测试数据
  - 合并特征和标签
  - 创建时间索引
  - 提取特征列

### 5. 特征工程
- **feature_engineering.py** (140行)
  - `FeatureEngineer` 类
  - 构建滞后特征
  - 处理缺失值
  - 统一处理训练集和测试集

### 6. 模型训练
- **model_trainer.py** (300行)
  - `ModelTrainer` 类
  - 准备训练数据
  - 创建DMatrix（支持样本权重）
  - 超参数随机搜索
  - 训练最终模型
  - 模型评估

### 7. 结果评估
- **evaluator.py** (290行)
  - `ModelEvaluator` 类
  - 测试集预测
  - 计算评估指标
  - 保存所有结果
  - 生成可视化图表

## 📄 配置文件

### 1. 默认配置
- **config.yaml** (80行)
  - 分类任务默认配置
  - 100次超参数搜索
  - 启用样本权重

### 2. 回归配置
- **config_regression.yaml** (80行)
  - 回归任务配置
  - 更大的超参数搜索空间
  - 适合连续值预测

### 3. 快速测试配置
- **config_quick_test.yaml** (60行)
  - 仅10次超参数搜索
  - 减少boosting轮数
  - 适合快速验证和调试
