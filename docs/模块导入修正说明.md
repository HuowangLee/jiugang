# 模块导入修正说明

## 修正日期
2025-10-29

## 修正目的
根据项目的实际目录结构，修正所有Python文件中的模块导入方式，使其符合Python包管理的标准规范。

## 目录结构
```
jiugang/
├── main.py                 # 主入口文件
├── src/                    # 源代码包
│   ├── __init__.py        # 包初始化文件（新增）
│   ├── config_manager.py
│   ├── data_loader.py
│   ├── evaluator.py
│   ├── feature_engineering.py
│   ├── model_trainer.py
│   ├── utils.py
│   └── zhushi.py
├── tests/                  # 测试文件
│   ├── test_data_loading.py
│   └── test_sample_weights.py
└── config/                 # 配置文件目录
    ├── config.yaml
    ├── config_ahead.yaml
    ├── config_realtime.yaml
    └── ...
```

## 修正内容

### 1. 主入口文件 (main.py)

**修改前:**
```python
from config_manager import ConfigManager
from data_loader import DataLoader
from feature_engineering import FeatureEngineer
from model_trainer import ModelTrainer
from evaluator import ModelEvaluator
```

**修改后:**
```python
from src.config_manager import ConfigManager
from src.data_loader import DataLoader
from src.feature_engineering import FeatureEngineer
from src.model_trainer import ModelTrainer
from src.evaluator import ModelEvaluator
```

### 2. 源代码模块内部导入

#### src/data_loader.py
**修改前:** `from utils import ...`  
**修改后:** `from src.utils import ...`

#### src/model_trainer.py
**修改前:** `from utils import ...`  
**修改后:** `from src.utils import ...`

#### src/evaluator.py
**修改前:** `from utils import ...`  
**修改后:** `from src.utils import ...`

#### src/feature_engineering.py
**修改前:** `from utils import ...`  
**修改后:** `from src.utils import ...`

### 3. 测试文件导入

#### tests/test_data_loading.py
**修改前:**
```python
from config_manager import ConfigManager
from data_loader import DataLoader
config_files = ['config_realtime.yaml', ...]
```

**修改后:**
```python
from src.config_manager import ConfigManager
from src.data_loader import DataLoader
config_files = ['config/config_realtime.yaml', ...]
```

#### tests/test_sample_weights.py
**修改前:** `from utils import ...`  
**修改后:** `from src.utils import ...`

### 4. 新增文件

创建了 `src/__init__.py` 文件，使 `src` 目录成为一个正式的Python包：

```python
"""
src包：包含所有核心模块
"""

__version__ = '1.0.0'
```

## 优势

1. **标准化**: 符合Python包管理的标准规范
2. **清晰性**: 明确显示模块来源，避免命名冲突
3. **可维护性**: 更易于理解项目结构
4. **可扩展性**: 便于将来添加更多子包
5. **IDE支持**: 现代IDE可以更好地识别和自动补全

## 运行方式

### 主程序运行
从项目根目录运行：
```bash
python main.py --config config/config.yaml
```

### 测试运行
从项目根目录运行：
```bash
python tests/test_data_loading.py
python tests/test_sample_weights.py
```

## 注意事项

1. 所有命令都应该从项目根目录（jiugang/）运行
2. 确保Python能够找到项目根目录（已经在sys.path中或者通过PYTHONPATH设置）
3. 如果在其他目录运行，可能需要将项目根目录添加到PYTHONPATH

## 兼容性

修正后的导入方式与以下环境兼容：
- Python 3.6+
- 所有主流操作系统（Windows、Linux、macOS）
- 标准Python包管理工具（pip、conda等）

## 验证

可以运行以下命令验证导入是否正确：
```bash
python -c "from src.config_manager import ConfigManager; print('✓ 导入成功')"
```

如果看到错误 `ModuleNotFoundError: No module named 'src'`，请确保：
1. 从项目根目录运行
2. src/__init__.py 文件存在
3. 当前目录在Python的搜索路径中
