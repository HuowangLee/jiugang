# 特征重要性保存说明

## 功能概述

训练完成后，系统会自动保存模型的特征重要性分析结果，包括：
1. **CSV文件**：包含所有特征及其重要性得分
2. **可视化图表**：Top 30 重要特征的柱状图

## 输出文件

在训练输出目录中会生成以下文件：

### 1. feature_importance.csv
包含所有特征的重要性得分，格式如下：
```
feature_name,importance_gain
feature_1,1234.56
feature_2,987.65
...
```

- `feature_name`: 特征名称（与训练时使用的特征列名完全对应）
- `importance_gain`: 特征的增益重要性得分（降序排列）

### 2. feature_importance.png
可视化图表，显示前30个最重要的特征，以水平柱状图形式展示。

## 配置选项

在配置文件的 `output` 部分：

```yaml
output:
  save_feature_importance: true  # 是否保存特征重要性（默认: true）
```

## 特征重要性计算方式

- **主要方式**: 使用 `gain` 类型计算特征重要性
  - gain 表示该特征对模型性能提升的平均贡献
- **备选方式**: 如果 gain 不可用，则使用 `weight` 类型
  - weight 表示该特征在所有树中被使用的次数

## 使用场景

1. **特征选择**: 识别最重要的特征，去除冗余特征
2. **业务理解**: 了解哪些因素对预测结果影响最大
3. **模型优化**: 基于重要性进行特征工程改进
4. **模型解释**: 向业务人员解释模型的决策依据

## 注意事项

1. 特征名称与数据加载时使用的列名完全一致
2. 滞后特征会以 `原特征名_lag_N` 的形式显示
3. 如果某个特征的重要性为0，说明该特征未被模型使用
4. 可视化图表默认只显示前30个特征，完整列表请查看CSV文件

## 示例

运行训练后，在输出目录（如 `output-ahead-20251027_001810/`）中可以找到：
- `feature_importance.csv`: 完整特征重要性列表
- `feature_importance.png`: Top 30 特征重要性可视化

查看特征重要性：
```python
import pandas as pd
fi = pd.read_csv('output-ahead-20251027_001810/feature_importance.csv')
print(fi.head(10))  # 查看前10个最重要特征
```
